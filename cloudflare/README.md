# RedGrid Cloudflare Sync Setup Guide (ক্লাউড সিঙ্ক গাইড)

এই নির্দেশিকাটি অনুসরণ করে আপনি খুব সহজেই সম্পূর্ণ বিনামূল্যে **Cloudflare Workers** এবং **Cloudflare D1** (সার্ভারলেস SQLite) ব্যবহার করে আপনার RedGrid অ্যাপের জন্য একটি হাই-স্পিড রিয়েল-টাইম ক্লাউড সিঙ্ক ব্যাকএন্ড চালু করতে পারবেন।

> **Cloudflare D1 কেন সেরা?**
> - **ফ্রি টিয়ার:** প্রতিদিন ৫০ লক্ষ (5 Million) রিড এবং ১ লক্ষ (100,000) রাইট সম্পূর্ণ ফ্রি!
> - **নো ইনঅ্যাক্টিভিটি স্লিপ:** Supabase-এর মতো ৭ দিন পর প্রজেক্ট পজ/স্লিপ হয় না।
> - **বাংলাদেশ এজ নেটওয়ার্ক:** ঢাকা ও চট্টগ্রামে Cloudflare-এর লোকাল ডেটাসেন্টার থাকায় <২০ms ল্যাটেন্সিতে সুপারফাস্ট সিঙ্ক হয়।
> - **নেটিভ SQLite:** RedGrid মোবাইল অ্যাপের লোকাল SQLite ডেটাবেসের সাথে হুবহু সামঞ্জস্যপূর্ণ।

## 🚀 দ্রুত সেটআপ (Quick Step-by-Step)

### ১. পূর্বশর্ত (Prerequisites)
- আপনার কম্পিউটারে [Node.js](https://nodejs.org/) (v18 বা পরবর্তী) ইনস্টল থাকতে হবে।
- একটি ফ্রি [Cloudflare Account](https://dash.cloudflare.com/sign-up)।

### ২. Wrangler CLI ইনস্টল ও লগইন
টার্মিনাল বা কমান্ড প্রম্পট খুলে নিচের কমান্ডটি দিন:
```bash
npm install -g wrangler
```
এবার Cloudflare অ্যাকাউন্টে লগইন করুন:
```bash
wrangler login
```
*(ব্রাউজার খুলবে এবং সেখানে "Allow" ক্লিক করলেই লগইন সম্পন্ন হবে)*

### ৩. এই ডিরেক্টরিতে যান (Navigate to cloudflare folder)
```bash
cd cloudflare
```

### ৪. Cloudflare D1 ডেটাবেস তৈরি করুন
নিচের কমান্ডটি চালান:
```bash
wrangler d1 create redgrid-db
```
কমান্ডটি সফল হলে টার্মিনালে নিচের মতো একটি আউটপুট পাবেন:
```toml
[[d1_databases]]
binding = "DB"
database_name = "redgrid-db"
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

### ৫. `wrangler.toml` ফাইলে Database ID বসান
`cloudflare/wrangler.toml` ফাইলটি কোনো টেক্সট এডিটরে খুলুন এবং ধাপ ৪-এ পাওয়া `database_id` টি বসিয়ে দিন:
```toml
[[d1_databases]]
binding = "DB"
database_name = "redgrid-db"
database_id = "আপনার-কপি-করা-আইডি"
```

### ৬. ডেটাবেস স্কিমা তৈরি করুন (Execute Schema)
ক্লাউড ডেটাবেসে টেবিলগুলো তৈরি করতে এই কমান্ডটি দিন:
```bash
wrangler d1 execute redgrid-db --file=./schema.sql --remote
```

### ৭. ওয়ার্কার ডিপ্লয় করুন (Deploy Worker)
এবার আপনার ব্যাকএন্ড API লাইভ করতে চালান:
```bash
wrangler deploy
```
সফলভাবে ডিপ্লয় হলে আপনি আপনার লাইভ ব্যাকএন্ড URL পাবেন, যেমন:
```text
https://redgrid-sync.<your-subdomain>.workers.dev
```

### ৮. (ঐচ্ছিক কিন্তু সুপারিশকৃত) গোপন সিঙ্ক কি (Sync Key) সেট করুন
আপনার ব্যাকএন্ডে অননুমোদিত অ্যাক্সেস ঠেকাতে একটি পাসওয়ার্ড/সিক্রেট কি সেট করতে পারেন:
```bash
wrangler secret put SYNC_KEY
```
টার্মিনালে আপনার পছন্দের একটি গোপন পাসওয়ার্ড লিখে এন্টার চাপুন (যেমন: `MyRedGridSecretPass2026!`)।

## 📱 RedGrid মোবাইল অ্যাপে কানেক্ট করার নিয়ম

1. RedGrid অ্যাপটি ওপেন করুন।
2. হোম স্ক্রিনের উপরে ডানদিকের **Cloud Sync** আইকনে (☁️) ট্যাপ করুন।
3. **Worker URL** ঘরে আপনার ওয়ার্কারের লিঙ্কটি দিন:
   `https://redgrid-sync.<your-subdomain>.workers.dev`
4. আপনি যদি ধাপ ৮-এ `SYNC_KEY` সেট করে থাকেন, তবে **Sync Key** ঘরে আপনার সেই গোপন পাসওয়ার্ডটি দিন (না দিলে ফাঁকা রাখুন)।
5. **"পরীক্ষা ও সিঙ্ক" (Test & Sync)** বাটনে ট্যাপ করুন।
6. সবুজ টিকচিহ্ন আসলে আপনার সমস্ত রক্তদাতার তথ্য ও হিস্ট্রি ক্লাউডে ব্যাকআপ হয়ে যাবে!

## 🔄 কীভাবে কাজ করে (Architecture Details)

- **অফলাইন-ফার্স্ট (100% Offline-First):** ইন্টারনেট সংযোগ না থাকলেও অ্যাপের সমস্ত ফিচার (ডোনার যোগ, এডিট, সার্চ, কল, হিস্ট্রি) স্বাভাবিকভাবে কাজ করে।
- **স্বয়ংক্রিয় ও অন-ডিমান্ড সিঙ্ক:**
  - হোম স্ক্রিনে উপর থেকে নিচে টানলে (Pull to Refresh) তৎক্ষণাৎ নতুন তথ্য সিঙ্ক হয়।
  - অ্যাপ ওপেন করলে বা সিঙ্ক বাটনে চাপলে অটো-সিঙ্ক হয়।
- **কনফ্লিক্ট রেজোলিউশন:** লাস্ট-রাইট-উইনস (`updated_at` টাইমস্ট্যাম্প) পদ্ধতির মাধ্যমে ডেটা ওভাররাইট হওয়া প্রতিরোধ করা হয়।
- **ফোন নম্বর প্রাইমারি শনাক্তকারী:** বিভিন্ন ডিভাইসে SQLite auto-increment ID আলাদা হলেও ডোনারের ফোন নম্বর ধরে সমস্ত হিস্ট্রি নিখুঁতভাবে সিঙ্ক হয়।

## 🛠️ সমস্যা সমাধান (Troubleshooting)

- **`Unauthorized` ত্রুটি দেখালে:** `wrangler secret put SYNC_KEY` এ যে পাসওয়ার্ড দিয়েছেন, অ্যাপের Sync Key ফিল্ডে হুবহু একই পাসওয়ার্ড দেওয়া হয়েছে কিনা নিশ্চিত করুন।
- **`D1 database binding 'DB' is missing` ত্রুটি দেখালে:** `wrangler.toml` ফাইলে `binding = "DB"` ঠিকমতো সংরক্ষিত আছে কিনা যাচাই করুন এবং পুনরায় `wrangler deploy` চালান।
- **লোকালি পরীক্ষা করতে চাইলে:** `wrangler dev` চালিয়ে লোকালহোস্টে টেস্ট করা যায়।
